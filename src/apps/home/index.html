Mudlet Packages

Installation

  1. Click the package icon, or the mpkg install command for packages that have one, to copy the installation script.
  2. Paste what you have copied into Mudlet's command line.
  3. Hit enter.
  4. Do the macarena.
  5. Heeeey, macarena.

Click on the GitHub icon to visit the repository. There might be help there. Or not. It depends.

If the mpkg command just gets you What? or similar from the game, your Mudlet doesn't have mpkg yet. to copy its installation script, paste that into Mudlet's command line, then try again.
